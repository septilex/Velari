# ⚡ Installation

## 1️⃣ Clone the repository

```bash
git clone https://github.com/YOUR_USERNAME/velari.git
```

## 2️⃣ Navigate into the project

```bash
cd velari
```

## 3️⃣ Install dependencies

```bash
npm install
```

## 4️⃣ Start the development server

```bash
npm run dev
```
